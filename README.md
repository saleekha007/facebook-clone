# Facebook Login Page Clone

A responsive Facebook-style login page UI built using HTML, CSS, and JavaScript.

## Live Demo

[View Live Website](https://saleekha007.github.io/facebook-clone/)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Facebook-inspired login page design
- Email and password input fields
- Responsive layout for desktop and mobile screens
- CSS hover effects and transitions
- JavaScript form interaction
- Clean and simple user interface

## Project Structure

```text
facebook-clone/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## Purpose

This project was created as a frontend development practice project to improve my skills in HTML, CSS, JavaScript, and responsive web design.

## Note

This is a frontend demo project. It does not provide real Facebook authentication or collect login credentials.
